# Changelog

[Chinese changelog](CHANGELOG.zh-CN.md)

## 1.0.0 — 2026-10-27

First public stable release, based on private development build 0.1.4.

- Highlight the Refresh button for current task item requirements and one-level crafting/assembly ingredients.
- Provide separate English and Chinese documentation.
- Distribute the BepInEx plugin and its two data tables; install the loader separately.
- Align the plugin, assembly, package and release version as 1.0.0.
- Preserve the existing gameplay logic.

Versioning follows the major.minor.patch convention: patches for compatible fixes, minor versions for compatible additions, and major versions for incompatible changes. A first public release does not have to start at 1.0.0; this project uses it to mark the transition from private development to its first stable public feature set.
