# 波西亚取物

[英文说明](README.md) · [下载最新版本](https://github.com/jeanmuss/portia-grab-items/releases/latest)

**点击“刷新”，更新当前任务所需物品，并同时列出其上一级制作、装配材料。**

适用于《波西亚时光》电脑端 Steam 版本的取物插件。按 **F8** 打开面板，选择 **“当前任务”**，接取或推进任务后点击 **“刷新”**，即可重新读取当前需求。

## 特色功能：刷新当前任务需求

1. 载入存档，按 **F8** 打开面板。
2. 选择 **“当前任务”** 类别，点击 **“刷新”**。
3. 查看目前支持读取的收集物品目标和商会委托。
4. 在同一面板中领取任务所需物品，或它们的直接制作、装配材料。

**[T]** 表示任务直接需要的物品，**[M]** 表示上一级材料。材料**只向前追溯一级**，不会继续展开“材料的材料”。存在多种配方时合并列出其材料，同一物品只显示一次。

列表在点击刷新时读取游戏当前状态，不会持续在后台跟踪任务。目前支持物品收集类目标，不代表能识别所有类型的任务，也不会自动完成任务。没有可靠名称或无法拾取的物品不会列入。

## 其他功能

- 物品图标与中英文名称并列展示。
- 支持中文名、英文名和物品编号搜索。
- 根据本游戏物品设置分类；博物馆页标示已捐赠状态。
- 左键领取 **1 件**，右键领取 **10 件**，添加前检查背包容量。
- 面板打开时释放鼠标，并抑制游戏操作输入。

## 安装

**当前版本：1.0.0。** 需要电脑端 Steam 游戏和 **BepInEx 5** 加载器。开发环境使用 Windows 64 位、BepInEx **5.4.22**、Unity **2017.4** 和 Mono CLR **2.0**。

1. 关闭游戏。
2. 从[加载器官方发布页](https://github.com/BepInEx/BepInEx/releases/tag/v5.4.22)安装 Windows 64 位的 BepInEx 5。加载器需要单独安装。
3. 从[本插件发布页](https://github.com/jeanmuss/portia-grab-items/releases/latest)下载 **PortiaGrabItems-1.0.0-BepInEx.zip**。GitHub 自动生成的源码压缩包不是可直接安装的插件包。
4. 将压缩包解压到游戏安装目录，确保以下三个文件直接位于 `BepInEx/plugins/`：
   - `PortiaGrabItem.dll`
   - `PortiaGrabItem.names.tsv`
   - `PortiaGrabItem.recipes.tsv`
5. **通过 Steam 正常启动游戏**，载入存档后按 **F8**。不需要通过单独的接口启动。

不要把这三个文件再放入下一层子目录。本插件使用 **BepInEx**，不是可交给 Unity Mod Manager 安装的包；尚未验证与该加载器及其他插件的兼容性。插件通过运行时补丁工作，无须替换游戏脚本或游戏程序集。

## 更新与卸载

更新前关闭游戏，备份原有三个插件文件，再用新版替换。卸载时移走这三个文件即可。已领取并经游戏保存的物品仍会保留；任务物品可能影响剧情进度，领取前请保留存档备份。
